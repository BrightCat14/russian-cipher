# russian-cipher

превращает русский текст в "месево" из юникод-символов и обратно. детерминированно и обратимо: каждая русская буква и знак пунктуации заменяется на уникальный символ.

## Использование

```bash
python3 cipher.py encode "Съешь же ещё этих мягких французских булок, да выпей чаю"
python3 cipher.py decode '!(:?% *: :—{ "><& ¤;^¢<& ΦΔ§£∇≈¶Ω¢<& ©≈¦€¢~ ®§ ¥Ξ₽:± Ψ§∑'
python3 cipher.py table   # показать таблицу замен
python3 cipher.py check   # самопроверка round-trip
python3 cipher.py         # интерактивный режим
```

## Правила

- кодируются только русские буквы (верхний и нижний регистр) и пунктуация.
- пробелы, переносы строк и не-кириллица (латиница, цифры) остаются как есть.
- не используй в исходном тексте сами символы-шифры (например `§` или `!`) - они принадлежат алфавиту шифра и расшифруются как буквы.

## Настройка

таблицы замен лежат в начале `cipher.py` в словарях `LOWER`, `UPPER`, `PUNCT` - просто меняй символы там. все символы должны быть уникальными, это проверяет команда `check`.
